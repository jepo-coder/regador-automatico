El problema

El riego manual puede provocar exceso o falta de agua. IrriSmart Automation busca automatizar este proceso utilizando sensores y programación.

Cómo funciona

  1. El sensor de humedad mide la humedad del suelo.
  2. Python recibe y procesa el valor.
  3. El sistema compara la humedad con un nivel mínimo (umbral).
  4. Si la humedad es demasiado baja, se activa el riego.
  5. Si la humedad es suficiente, la bomba permanece apagada.

Código Python

Programación orientada a objetos: cada parte del sistema es una clase. La versión completa (con Flask) está en app.py.

class SensorHumedad:
    """Simula el sensor: devuelve la humedad (0-100 %)."""
    def __init__(self, humedad_inicial=50):
        self.humedad = humedad_inicial
    def leer(self):
        return self.humedad

class ElectroValvula:
    """Deja pasar o corta el agua."""
    def __init__(self):
        self.abierta = False
    def abrir(self):  self.abierta = True
    def cerrar(self): self.abierta = False

class ProgramadorHorario:
    """Guarda las horas y la acción de cada una."""
    def __init__(self):
        self.horarios = {"07:00": "Riego", "12:00": "Revision", "18:00": "Riego"}
    def accion_a(self, hora):
        return self.horarios.get(hora, "Sin accion")

class SistemaRiego:
    """Controlador: compara humedad y umbral y decide."""
    def __init__(self, sensor, valvula, programador, umbral=40):
        self.sensor, self.valvula = sensor, valvula
        self.programador, self.umbral = programador, umbral
    def evaluar(self):
        humedad = self.sensor.leer()
        if humedad < self.umbral:   # suelo seco
            self.valvula.abrir()
        else:                       # humedad suficiente
            self.valvula.cerrar()
        return {"humedad": humedad, "umbral": self.umbral,
                "riego_activo": self.valvula.abierta}

Contacto

Preguntas frecuentes

¿Qué problema busca resolver IrriSmart?

El riego manual puede dar demasiada o muy poca agua. IrriSmart automatiza la decisión usando un sensor y programación.

¿Cómo detecta cuándo una planta necesita agua?

Mide la humedad del suelo y la compara con un umbral mínimo. Si está por debajo, indica que hay que regar.

¿Qué función cumple el sensor?

Detecta la humedad del suelo y entrega ese dato al controlador.

¿Qué hace Python?

Procesa el valor del sensor, aplica la regla de comparación y decide si abrir o cerrar la electroválvula.

¿Cómo ayuda a ahorrar agua?

Al regar solo cuando el suelo está seco, evita riegos innecesarios. La página lo muestra como simulación; no presenta mediciones reales de ahorro.
